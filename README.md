# Bài tập: Nhúng CSS vào trang HTML

Trang có một tiêu đề màu xanh lá và một đoạn văn màu xanh dương theo hình mẫu.

- Phần 1: `inline.html` dùng thuộc tính `style` trực tiếp trên thẻ HTML.
- Phần 2: `internal.html` dùng thẻ `<style>` trong `<head>`.
- Phần 3: `external.html` dùng `<link>` để liên kết file `style.css`.
- `index.html` là trang mặc định, sử dụng external CSS.

Mở từng file HTML bằng trình duyệt để xem kết quả. Cả ba cách cho cùng màu sắc; đoạn văn kế thừa màu từ `body`.
